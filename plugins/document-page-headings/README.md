# typedoc-plugin-document-page-headings

[![NPM License](https://img.shields.io/npm/l/typedoc-plugin-document-page-headings)](https://www.npmjs.com/package/typedoc-plugin-document-page-headings) [![NPM Version](https://img.shields.io/npm/v/typedoc-plugin-document-page-headings)](https://www.npmjs.com/package/typedoc-plugin-document-page-headings) [![NPM dev or peer Dependency Version](https://img.shields.io/npm/dependency-version/typedoc-plugin-document-page-headings/peer/typedoc)](https://www.npmjs.com/package/typedoc) [![GitHub Issues by label](https://img.shields.io/github/issues/mrfigg/typedoc-plugins/document-page-headings)](https://github.com/mrfigg/typedoc-plugins/issues)

A plugin for TypeDoc that adds document kind tags to document page headings.

## Example

A basic example is available at [https://mrfigg.github.io/typedoc-plugins/document-page-headings](https://mrfigg.github.io/typedoc-plugins/document-page-headings).

## Installation

```sh
npm install -D typedoc-plugin-document-page-headings
```
